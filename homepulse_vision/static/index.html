1 · Pick a doorbell event

Frames are drawn by the server at request time (simulated camera). Passes carry a real Ed25519 signature.

…or upload a frame

Privacy

  • Uploaded images are processed in memory and never stored or logged.
  • Face detection answers only “is someone there?”. No face recognition, no identity, no stored faces; landmarks are discarded.
  • Text and QR content seen by the camera are shown as untrusted data. The agent never follows them.
  • The camera, the lock and the family phone are simulated.

2 · Watch perception drive the agent

  1. OpenCV 5 checks the frame: blur, darkness, backlight, watermark; decodes QR; reads text (DB + CRNN); detects presence (YuNet).
  2. Nova 2 Lite on Amazon Bedrock plans the next tool call from those measurements. It never sees pixels.
  3. If the frame is too poor to trust, the agent improves the view or asks for a new snapshot before deciding.
  4. unlock_door passes only a deterministic guard: a verified one-time pass seen in this session, or family approval.
